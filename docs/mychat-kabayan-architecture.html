Minimal architecture, shown as product UI

The phone is the architecture: user input flows through the React shell, Zustand state, myGENE assistant logic, and Matrix-ready chat services while preserving a familiar messaging layout.

1 React chat shellApp.jsx, BottomNav and screens create the mobile frame: header, chips, message thread and composer.
2 Zustand stateNavigation, active tab, messages, records and demo/auth mode stay in one lightweight store.
3 Kabayan workflowsSOS, documents, benefits, remittance and country guide content are exposed as chat-first actions.
4 Matrix-ready servicesExisting Matrix client remains the path for rooms, real messages and future backend integrations.
Design correction: keep dashboards secondary. The main surface should always read as a messenger: conversation thread + quick replies + composer.

Chat app design rules

Conversation first

The center of the screen is always a message thread, not a dashboard or infographic.

Actions as replies

SOS, Docs and Benefits appear as quick replies/cards inside chat context.

One thumb flow

Bottom nav and composer stay fixed; primary action is always typing or tapping a prompt.
